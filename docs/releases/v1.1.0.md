# Blue-Star Pet v1.1.0

## Summary

本版在 v1.0.0 的基础上，增加三格充能与大共鸣、星空心核、台座腿型和钉住参照，并修复跨屏共鸣定位和窗口夹持时的回摆。

## Highlights

- **充能与大共鸣**：有效时间、洞察和成功回收文件可积累充能；三格满充后可触发带桌面折射和边缘反弹的大共鸣。充能等级与格内进度随用户设置保存。
- **心核与腿型**：增加星空心核及辐射/台座腿型；吸收回弹按成功回收文件的总大小变化。修复台座压迫时部分脚尖、脚跟未一起收拢的问题。
- **钉住参照**：可把媒体或已打开的窗口交给脚尖夹持，协同拖动、缩放并通过甩动松脱；修复外部窗口调整大小时的反复拉回、闪烁和阻塞。
- **共鸣定位**：锁定发波瞬间的心核位置，并按桌宠与波纹窗口的实际缩放换算，修复不同 DPI 显示器上的波心偏移、扩张跳位和蓄力跨屏定位。
- **音效与绘制**：更新充能升级、彗星捕获星闪和大共鸣音效；大共鸣使用深厅混响发波声，背景音独立播放。优化常驻动画分配和波纹绘制，不将其描述为所有场景的 CPU/GPU 占用都降低。

## Compatibility and upgrade notes

- Windows 便携版；使用 .NET Framework/WPF，当前验收环境为 64 位 Windows 11。
- 先通过「本能 → 退出桌宠」关闭旧版，再在原目录覆盖 `BlueStar.exe`。图像、界面、着色器和音效均已嵌入，无需单独安装素材。
- 保持现有程序集身份版本，仅更新文件/信息版本。建议保持安装路径；移动到不同目录可能导致 Windows/.NET 将其视为另一份用户设置，从而重新使用默认配置。
- 无需手工修改配置文件。新增设置使用默认值；星轨暂存记录不跨进程保存，退出后原文件仍在原处。
- 「回归星之怀抱」会清空整个 Windows 回收站；此项原有行为未改变。媒体夹持兼容性取决于默认应用及其窗口机制。
- 本版保留既有非官方同人和原作素材归属声明，未另行选择开源许可证。

## Validation and known limits

- 主管交付的功能验收覆盖三档桌宠尺寸、台座压迫/解封、窗口夹持、音效读回，以及主屏 150%/副屏 125% 的共鸣定位。
- 最近的多屏验收为 48 个采样帧，普通共鸣最大波心误差约 1.13 px，大共鸣约 1.03 px。证据来自窗口像素和 DWM 物理边界；完整副屏合成截图未通过背景校验，不将其列为通过项目。
- 发布构建另行检查必需嵌入资源、音频一致性和 ZIP 内容。既有交互验收不代表已覆盖所有显示器配置、外部查看器或显卡。
- 常驻动画与桌面折射仍有 CPU/GPU 开销；高分辨率下的实际负担取决于硬件与桌面合成。
